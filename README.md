# One Line, Big Laugh — make.fun entry

One hilarious line, 200 characters or fewer, that lands entirely on its own:

> I told my landlord the faucet was leaking. He called it a 'free water feature' and raised my rent.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character rule.
